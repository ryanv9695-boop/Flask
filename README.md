# Projeto Flask 🚀

Este é um projeto simples desenvolvido com [Flask](https://flask.palletsprojects.com/), um microframework leve e poderoso para desenvolvimento web utilizando Python.

## 🛠️ Tecnologias Utilizadas

* **Python**
* **Flask**

## 🚀 Como executar o projeto

Siga os passos abaixo para configurar e rodar a aplicação no seu ambiente local:

# 1. Criar ambiente virtual
python -m venv .venv

# 2. Ativar ambiente (Windows)
.venv\Scripts\activate

# 3. Instalar o framework
pip install Flask
